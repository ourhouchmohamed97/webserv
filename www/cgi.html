Execution Context

CGI scripts are executed in a fork-exec model within the C++98 core. The server captures standard output directly to this terminal. Environment variables such as PATH_INFO, QUERY_STRING, and REMOTE_ADDR are passed automatically.

Security Sandbox

  • Resource limits enforced (CPU/RAM/Timeout) to prevent script hang.
  • Read-only access to core server configuration files.
  • Script execution runs under isolated webserv_cgi user.
